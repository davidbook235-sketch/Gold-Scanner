# 🥇 Gold Signal Scanner

XAUUSD (Gold) के लिए मल्टी-इंडिकेटर बाय/सेल सिग्नल स्कैनर।

## फीचर्स
- 7+ टेक्निकल इंडिकेटर्स (RSI, MACD, Bollinger Bands, EMA, Stochastic, ADX, Supertrend, ATR)
- कॉन्फिडेंस स्कोर के साथ बाय/सेल/न्यूट्रल सिग्नल
- ATR आधारित एंट्री, स्टॉप लॉस और 3 टेक प्रॉफिट लेवल्स
- इंटरैक्टिव टेक्निकल चार्ट (Plotly)
- मल्टी-टाइमफ्रेम सपोर्ट (15m, 1h, 4h, 1d)
